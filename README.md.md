**（1）制作サイトのタイトル**
・「こどもNESA」
**（2）制作サイトの説明**
・子ネズミがCHEESE BANKにチーズを預け、熟成工場で育てながら、チーズの成長を楽しむ未来を描いたネズミ世界版こどもNESAの紹介LP。
**（3）工夫した点・こだわった点**
・制作プロセス（仮想の事業会社・サービス内容を設定し、PRD・デザインMDを先に整理してからLPを制作した）
・AIエージェントであたりを作成（今回は仕様書をあたりとした）。あたりをベースに可能な限り自分でコードを直接編集し、メモをコメントタグで残した。
・画像データの淵に、背景色と同色の円（楕円）を重ねて切り抜くことでチーズを表現し、没入感を高めた。
**（4）難しかった点・次回トライしたいこと（または機能）**
・AIエージェントを使用してコードを書くときに何もルールを指示しなかったため、CSSの継ぎ足し・パッチ当てが繰り返され、CSSが肥大化してしまった。
　→これに対してマスタールールのようなものを作成して必ず読み込ませようと考えたが、トークンの固定費が増大してしまうデメリットに直面。
　→結果、ルールは策定したが、プロジェクト毎にどのルールに従うかマニュアルで指示することとしたけど、何か良い解決策があれば知りたい！
